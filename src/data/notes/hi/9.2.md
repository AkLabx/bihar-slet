### भाग 1: ऑपरेटिंग सिस्टम: कार्य एवं प्रमुख प्रकार

* **परिभाषा:** ऑपरेटिंग सिस्टम (OS) आवश्यक सिस्टम सॉफ्टवेयर है जो यूजर और कंप्यूटर हार्डवेयर के बीच एक **इंटरफेस (मध्यस्थ)** का कार्य करता है।
* **प्रमुख कार्य:**
  1. *प्रोसेसर प्रबंधन (CPU शेड्यूलिंग)* — मल्टीप्रोग्रामिंग एवं टाइम-शेयरिंग का प्रबंधन।
  2. *मेमोरी प्रबंधन* — RAM एवं वर्चुअल मेमोरी का कुशल आवंटन।
  3. *फाइल प्रबंधन* — डायरेक्टरी एवं फाइलों का सुरक्षित रखरखाव (जैसे NTFS, FAT32)।
  4. *डिवाइस प्रबंधन* — डिवाइस ड्राइवर्स द्वारा इनपुट/आउटपुट उपकरणों का नियंत्रण।
* **बूटिंग प्रक्रिया:**
  * **कोल्ड बूटिंग:** कंप्यूटर के पूर्णतः बंद (Power Off) अवस्था से चालू करने की प्रक्रिया।
  * **वार्म बूटिंग:** पहले से चालू कंप्यूटर को रीस्टार्ट ($Ctrl+Alt+Delete$) करना।
  * **POST (Power-On Self-Test):** कंप्यूटर चालू होते ही BIOS द्वारा हार्डवेयर घटकों की कार्यक्षमता की स्व-जांच।

| ऑपरेटिंग सिस्टम प्रकार | उदाहरण | मुख्य विशेषताएं एवं लाइसेंस |
|---|---|---|
| **कमांड लाइन इंटरफेस (CLI / CUI)** | MS-DOS, UNIX Shell | केवल टेक्स्ट कमांड टाइप करके संचालन। |
| **ग्राफिकल यूजर इंटरफेस (GUI)** | Windows (10/11), macOS | आइकॉन्स, मेन्यू, माउस क्लिक द्वारा सरल दृश्य संचालन। |
| **ओपन सोर्स ऑपरेटिंग सिस्टम** | **Linux** (Ubuntu, RedHat, Debian), Android | स्रोत कोड (Source Code) सार्वजनिक रूप से निशुल्क उपलब्ध व संपादन योग्य। लिनक्स कर्नल के निर्माता: **लिनुस टॉर्वाल्ड्स (1991)**। |
| **क्लोज्ड / प्रोप्राइटरी OS** | Microsoft Windows, macOS, iOS | वाणिज्यिक लाइसेंस प्राप्त; स्रोत कोड गुप्त रहता है। |
| **मोबाइल ऑपरेटिंग सिस्टम** | Android (Google - लिनक्स आधारित), iOS (Apple) | टच-स्क्रीन आधारित पोर्टेबल डिवाइस OS। |

### भाग 2: माइक्रोसॉफ्ट ऑफिस सूट: वर्ड, एक्सेल एवं पावरपॉइंट

#### क. एमएस वर्ड (MS Word — वर्ड प्रोसेसर)
* **डिफॉल्ट फाइल एक्सटेंशन:** `.docx` (Office 2007 से वर्तमान) एवं `.doc` (पुराने संस्करण)।
* **महत्वपूर्ण शॉर्टकट कुंजियां:**
  * $Ctrl + A$: संपूर्ण दस्तावेज का चयन (Select All)
  * $Ctrl + C$ / $Ctrl + X$ / $Ctrl + V$: कॉपी / कट / पेस्ट
  * $Ctrl + Z$ / $Ctrl + Y$: अंडू / रीडू
  * $Ctrl + F$ / $Ctrl + H$: फाइंड / रिप्लेस
  * $Ctrl + K$: **हाइपरलिंक प्रविष्ट करना (Insert Hyperlink)**
  * $Ctrl + B$ / $Ctrl + I$ / $Ctrl + U$: बोल्ड / इटैलिक / रेखांकित (Underline)
  * **संरेखण (Alignment):** $Ctrl + L$ (Left), $Ctrl + E$ (Center), $Ctrl + R$ (Right), $Ctrl + J$ (Justify)
  * $F7$: **वर्तनी एवं व्याकरण जांच (Spelling & Grammar Check)**
  * $Shift + F7$: **थिसॉरस (Thesaurus — समानार्थी शब्दकोश खोजना)**

#### ख. एमएस एक्सेल (MS Excel — स्प्रेडशीट सॉफ्टवेयर)
* **डिफॉल्ट फाइल एक्सटेंशन:** `.xlsx` (पुराना: `.xls`)।
* **मूलभूत संरचना:** वर्कबुक में अनेक वर्कशीट्स होती हैं। वर्कशीट में पंक्तियां (संख्या 1, 2, 3...) तथा स्तंभ (अक्षर A, B, C...) होते हैं।
* **सेल:** पंक्ति और स्तंभ का कटान बिंदु। सक्रिय सेल का पता **'नेम बॉक्स'** में प्रदर्शित होता है (जैसे `B5`)।
* **फॉर्मूला नियम:** एक्सेल में कोई भी फॉर्मूला हमेशा **'=' (बराबर के चिह्न)** से शुरू होता है (जैसे `=SUM(A1:A10)` या `=AVERAGE(B1:B5)`).
* **प्रमुख शॉर्टकट कुंजियां:**
  * $F2$: सक्रिय सेल को **संपादित (Edit)** करना
  * $Alt + =$: **AutoSum (त्वरित योग)** फंक्शन जोड़ना
  * $F4$: सेल संदर्भ को एब्सोल्यूट/स्थिर (Lock with \$) करना
  * $Ctrl + ;$: आज की वर्तमान तारीख प्रविष्ट करना

#### ग. एमएस पावरपॉइंट (MS PowerPoint — प्रेजेंटेशन सॉफ्टवेयर)
* **डिफॉल्ट फाइल एक्सटेंशन:** `.pptx`।
* **स्लाइड शो कुंजियां:**
  * $F5$: प्रेजेंटेशन को **प्रथम स्लाइड से** स्लाइड शो मोड में चलाना
  * $Shift + F5$: **वर्तमान सक्रिय स्लाइड से** स्लाइड शो शुरू करना
  * $Esc$: स्लाइड शो को तुरंत समाप्त करना
  * $Ctrl + M$: प्रेजेंटेशन में **नई स्लाइड जोड़ना** *(सावधानी: $Ctrl+N$ नई प्रेजेंटेशन फाइल खोलता है)*

### भाग 3: नेटवर्किंग, इंटरनेट एवं संचार प्रोटोकॉल

```
         ┌─── 1. LAN (लोकल एरिया नेटवर्क) ─── एक कमरा, भवन या विद्यालय परिसर (1 किमी तक)
नेटवर्क ─┼─── 2. MAN (मेट्रोपॉलिटन एरिया नेटवर्क) ─── संपूर्ण नगर/शहर (जैसे केबल टीवी नेटवर्क)
के प्रकार └─── 3. WAN (वाइड एरिया नेटवर्क) ─── देश अथवा वैश्विक स्तर (इंटरनेट सबसे बड़ा WAN है)
```

#### क. इंटरनेट एवं प्रमुख प्रोटोकॉल
* **इंटरनेट के जनक:** **विंटन सेर्फ़ (Vinton Cerf)** एवं बॉब काह्न (TCP/IP के सह-निर्माता)।
* **WWW (World Wide Web):** वर्ष 1989 में सर्न (CERN) में **टिम बर्नर्स ली** द्वारा आविष्कृत।
* **प्रमुख प्रोटोकॉल चार्ट:**

| प्रोटोकॉल | पूर्ण नाम | कार्यप्रणाली एवं मानक पोर्ट |
|---|---|---|
| **TCP/IP** | Transmission Control Protocol / Internet Protocol | इंटरनेट का मूल आधार; डेटा को पैकेटों में विभाजित करना तथा गंतव्य तक सुरक्षित पहुंचाना। |
| **HTTP / HTTPS** | Hypertext Transfer Protocol (Secure) | वेब पेजों का अंतरण; HTTPS में डेटा **SSL/TLS एन्क्रिप्शन** द्वारा सुरक्षित रहता है (Port 443)। |
| **FTP** | File Transfer Protocol | नेटवर्क पर फाइलों को अपलोड व डाउनलोड करने हेतु (Port 20/21)। |
| **DNS** | Domain Name System | डोमेन नेम (जैसे `bihar.gov.in`) को संख्यात्मक IP पते (जैसे `164.100.150.10`) में बदलना ('इंटरनेट की फोनबुक')। |
| **DHCP** | Dynamic Host Configuration Protocol | नेटवर्क में जुड़े उपकरणों को स्वचालित रूप से गतिशील IP एड्रेस आवंटित करना। |

#### ख. ईमेल संचार प्रोटोकॉल
* **SMTP (Simple Mail Transfer Protocol):** ईमेल **भेजने (Outgoing / Sending Mail)** के लिए प्रयुक्त (मानक पोर्ट: 25)।
* **POP3 (Post Office Protocol v3):** सर्वर से कंप्यूटर पर ईमेल **प्राप्त करने / डाउनलोड करने** हेतु।
* **IMAP (Internet Message Access Protocol):** ईमेल को सीधे क्लाउड सर्वर पर रहकर पढ़ने और कई उपकरणों (मोबाइल, लैपटॉप) में सिंक रखने हेतु।
* **ईमेल संरचना:** `username@domain.com` | **CC (Carbon Copy):** सभी प्राप्तकर्ताओं को अन्य पते दिखते हैं। **BCC (Blind Carbon Copy):** दर्ज पते किसी अन्य को दिखाई नहीं देते (गोपनीयता)।

### भाग 4: साइबर सुरक्षा, मैलवेयर एवं सुरक्षा उपाय

#### क. प्रमुख मैलवेयर (हानिकारक सॉफ्टवेयर)

| मैलवेयर का प्रकार | कार्यप्रणाली एवं हानिकारक प्रभाव |
|---|---|
| **कंप्यूटर वायरस** | • Vital Information Resources Under Siege.<br>• किसी वैध निष्पादन योग्य फाइल (.exe आदि) से जुड़कर अपनी प्रतियां बनाता है और फाइलों को नष्ट करता है।<br>• विश्व का प्रथम पीसी वायरस: **'ब्रेन' (Brain - 1986)**। |
| **कंप्यूटर वॉर्म** | • इसे फैलने हेतु किसी होस्ट फाइल की जरूरत नहीं होती।<br>• नेटवर्क सुरक्षा खामियों का लाभ उठाकर स्वयं की लाखों प्रतियां बनाकर मेमोरी व बैंडविड्थ जाम कर देता है। |
| **ट्रोजन हॉर्स** | • एक **धोखेबाज प्रोग्राम** जो बाहर से उपयोगी सॉफ्टवेयर दिखता है, किंतु इंस्टॉल होने पर हैकर्स के लिए 'बैकडोर' खोल देता है। |
| **रैंसमवेयर** | • उपयोगकर्ता की फाइलों को जटिल क्रिप्टोग्राफी से **एन्क्रिप्ट (तालाबंद)** कर देता है तथा डिक्रिप्शन की के बदले फिरौती (बिटकॉइन आदि) मांगता है (जैसे WannaCry)। |
| **स्पाइवेयर एवं कीलॉगर** | • उपयोगकर्ता की अनुमति के बिना इंटरनेट गतिविधियों व कीबोर्ड के बटनों (Keystrokes) को रिकॉर्ड कर पासवर्ड चुराना। |

#### ख. प्रमुख साइबर हमले एवं सुरक्षा शब्दावली
* **फ़िशिंग:** विश्वसनीय संस्थाओं (बैंक आदि) जैसी दिखने वाली नकली वेबसाइट/ईमेल द्वारा उपयोगकर्ताओं को ठगकर पासवर्ड व ओटीपी चुराना।
* **स्पूफिंग:** अपनी पहचान छिपाकर किसी अधिकृत स्रोत या IP का नकली रूप धारण करना।
* **DoS / DDoS:** किसी सर्वर पर एक साथ लाखों फर्जी अनुरोध भेजकर सर्वर को ठप कर देना।
* **फ़ायरवॉल:** निजी नेटवर्क (LAN) और बाहरी असुरक्षित नेटवर्क (इंटरनेट) के बीच अनधिकृत प्रवेश रोकने वाला **सुरक्षा फिल्टर (हार्डवेयर या सॉफ्टवेयर)**।
* **भारतीय सूचना प्रौद्योगिकी अधिनियम, 2000 (IT Act 2000):**
  * प्रभावी: 17 अक्टूबर 2000।
  * धारा 43 व 66: अनधिकृत हैकिंग व डेटा क्षति हेतु कठोर दंड।
  * धारा 66E: निजता उल्लंघन हेतु दंड।

### भाग 5: परीक्षा-उपयोगी महत्वपूर्ण स्मरणीय बिंदु

> [!IMPORTANT]
> 1. **लिनक्स:** ओपन-सोर्स OS (लिनुस टॉर्वाल्ड्स 1991)।
> 2. **MS Word शॉर्टकट्स:** $Ctrl+K$ = हाइपरलिंक, $F7$ = स्पेलिंग चेक, $Shift+F7$ = थिसॉरस।
> 3. **MS Excel:** फॉर्मूला हमेशा '=' से शुरू; सक्रिय सेल 'नेम बॉक्स' में दिखता है; $Alt+=$ = AutoSum।
> 4. **MS PowerPoint:** $F5$ = आरंभ से स्लाइड शो, $Shift+F5$ = वर्तमान स्लाइड से, $Ctrl+M$ = नई स्लाइड।
> 5. **ईमेल प्रोटोकॉल:** भेजने हेतु = SMTP (Port 25); डाउनलोडिंग हेतु = POP3 / IMAP।
> 6. **DNS:** डोमेन नेम को IP एड्रेस में अनुवाद करना।
> 7. **फ़िशिंग:** फर्जी वेबसाइट द्वारा वित्तीय पासवर्ड चुराना।
> 8. **फ़ायरवॉल:** अनधिकृत नेटवर्क ट्रैफिक को रोकने वाला सुरक्षा कवच।
