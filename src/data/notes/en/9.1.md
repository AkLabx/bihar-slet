### Part 1: Evolution of Computers & The Five Generations

* **Father of the Computer:** **Charles Babbage** — conceived the mechanical 'Analytical Engine' in 1837.
* **World's First Computer Programmer:** **Lady Ada Lovelace** (developed the first algorithm for Babbage's Analytical Engine).
* **Father of Modern Computer Science:** **Alan Turing** (Turing Machine concept and computational foundation).

| Generation | Chronological Period | Core Electronic Technology | Memory Storage & Programming Language | Notable Computer Systems |
|---|---|---|---|---|
| **1st Generation** | 1940–1956 | **Vacuum Tubes (Thermionic Valves)** | Magnetic Drums; **Machine Language (Binary: 0 and 1)** | ENIAC (First general-purpose electronic digital computer), EDVAC, UNIVAC-I |
| **2nd Generation** | 1956–1963 | **Transistors** (Invented in 1947 by Bardeen, Brattain, and Shockley at Bell Labs) | Magnetic Core Memory; **Assembly Language & Early High-Level Languages (FORTRAN, COBOL)** | IBM 1401, IBM 1620, CDC 1604 |
| **3rd Generation** | 1964–1971 | **Integrated Circuits (IC Chips / Microchips)** (Pioneered by Jack Kilby in 1958) | Semiconductor Magnetic Disks; Time-Sharing Operating Systems; BASIC, Pascal | IBM 360 series, PDP-8 |
| **4th Generation** | 1971–Present | **Microprocessors (VLSI - Very Large Scale Integration)** | Semiconductor RAM and ROM; C, C++, Relational Databases (RDBMS); Personal Computers (PCs) & Internet | Intel 4004 (First single-chip commercial microprocessor), IBM PC, Apple II |
| **5th Generation** | Present & Future | **ULSI (Ultra Large Scale Integration) & Artificial Intelligence (AI)** | Optical Storage, Cloud Storage, Quantum Computing; Natural Language Processing (NLP), Neural Networks | Robotics, Supercomputers (PARAM series), Autonomous AI systems |

### Part 2: Basic Computer Architecture & The Central Processing Unit (CPU)

Modern computer design is rooted in the **'Stored-Program Architecture'** conceptualized by mathematician **John von Neumann** in 1945:

```
[Input Devices] ──→ [Central Processing Unit (CPU)] ──→ [Output Devices]
 (Keyboard, Mouse)            │         ▲                 (Monitor, Printer)
                              │         │
                              ▼         │
                       [Primary Memory (RAM / ROM)]
                              │         ▲
                              ▼         │
                       [Secondary Storage (SSD / HDD)]
```

#### Core Components of the Central Processing Unit (CPU):
Referred to as the **'Brain of the Computer'**. CPU execution speed is calibrated in **Hertz (GHz / MHz)** or instruction throughput measured in **MIPS (Million Instructions Per Second)**.
1. **ALU (Arithmetic Logic Unit):**
   * Executes arithmetic computations (addition, subtraction, multiplication, division) and logical comparisons ($<, >, =, \le, \ge, \neq$).
2. **CU (Control Unit):**
   * Known as the **'Nervous System'** or 'Traffic Controller' of the computer system.
   * Fetches instructions from primary memory, decodes them into control signals, and directs operations of ALU, registers, and I/O units.
3. **Registers:**
   * Ultra-fast, high-speed, small-capacity temporary storage locations situated directly inside the CPU processor die.
   * Key registers include:
     * **Program Counter (PC):** Holds the memory address of the next sequential instruction to be fetched and executed.
     * **Accumulator (AC):** Temporarily stores intermediate arithmetic and logical results.
     * **Memory Address Register (MAR) & Memory Buffer Register (MBR):** Interface data bus and memory words.

### Part 3: Memory Hierarchy & Classification of Storage

In the computer memory hierarchy, moving from the top (registers) to the bottom (secondary storage): **access speed decreases, storage capacity expands, and cost per bit significantly decreases**:

```
           [CPU Registers]                 ← Fastest speed, smallest capacity, highest cost per bit
                  ▼
         [Cache Memory (L1, L2, L3)]       ← High-speed static buffer between CPU and RAM
                  ▼
      [Primary Memory (RAM / ROM)]         ← Main working memory of computer
                  ▼
  [Secondary Storage (SSD, HDD, USB Drive)] ← High-capacity, non-volatile, persistent, slower
```

#### A. Primary / Main Memory
1. **RAM (Random Access Memory):**
   * **Volatile / Temporary Storage:** Entire data contents are instantly wiped when electrical power is switched off.
   * Supports read and write operations; active applications and operating system files are loaded into RAM during execution.
   * *Static RAM (SRAM):* Constructed using bistable flip-flop latches; does not require periodic electrical refreshing; ultra-fast and expensive; utilized as **Cache Memory**.
   * *Dynamic RAM (DRAM):* Constructed using capacitor-transistor pairs; charges leak and require periodic refreshing; constitutes the primary system RAM.
2. **ROM (Read Only Memory):**
   * **Non-Volatile / Permanent Storage:** Data persists intact even after complete power shutdown.
   * Pre-programmed during manufacturing with boot code: the **BIOS (Basic Input/Output System)** and bootstrap loader program, collectively designated as **'Firmware'**.
   * Variants: **PROM** (Programmable ROM), **EPROM** (Erasable Programmable ROM using Ultraviolet light exposure), **EEPROM** (Electrically Erasable Programmable ROM — foundational technology for Flash USB drives and SSDs).
3. **Cache Memory:**
   * An extremely fast semiconductor SRAM buffer located between the processor cores and system RAM to store frequently accessed data and program instructions, eliminating CPU memory latency.

#### B. Data Storage Units & Conversion Chart

| Unit | Binary Equivalent / Dimension | Practical Context & Exam Takeaways |
|---|---|---|
| **Bit (b)** | Binary Digit: 0 or 1 | Smallest indivisible fundamental unit of digital information |
| **Nibble** | **4 Bits** | Half of a Byte; represents one hexadecimal character |
| **Byte (B)** | **8 Bits** | Standard fundamental unit required to encode a single ASCII character |
| **Kilobyte (KB)** | $1024\text{ Bytes} = 2^{10}\text{ Bytes}$ | Short text document or email |
| **Megabyte (MB)** | $1024\text{ KB} = 2^{20}\text{ Bytes}$ | MP3 audio file or high-resolution photograph |
| **Gigabyte (GB)** | $1024\text{ MB} = 2^{30}\text{ Bytes}$ | HD movie file or typical system RAM capacity |
| **Terabyte (TB)** | $1024\text{ GB} = 2^{40}\text{ Bytes}$ | Modern external Hard Disk Drive (HDD) or Solid State Drive (SSD) |
| **Petabyte (PB)** | $1024\text{ TB} = 2^{50}\text{ Bytes}$ | Enterprise cloud storage data centers |

### Part 4: Input & Output Peripheral Hardware

#### A. Major Input Devices
* **Keyboard:** Standard QWERTY layout (typically 104 keys). Houses Dedicated Function Keys from $F1$ to $F12$.
* **Mouse:** Handheld pointing device invented in 1964 by **Douglas Engelbart** at Stanford Research Institute.
* **Optical Mark Recognition (OMR):** Detects pencil/pen marks on pre-printed forms; universally deployed in competitive exam evaluation.
* **Optical Character Recognition (OCR):** Translates scanned printed or handwritten paper text into digital machine-editable text files.
* **Magnetic Ink Character Recognition (MICR):** Deployed across banking systems for rapid clearance of financial cheques; decodes 9-digit routing codes printed in specialized magnetic iron oxide ink along cheque footers.
* **Barcode Reader (BCR) & QR Code Scanner:** Optical sensors capturing 1D linear barcodes or 2D Quick Response matrix patterns.
* **Biometric Scanners, Webcams, Microphones, and Joysticks.**

#### B. Major Output Devices
* **Monitors (Visual Display Unit - VDU):**
  * Display technologies: Cathode Ray Tube (CRT), Liquid Crystal Display (LCD), Light Emitting Diode (LED), Organic LED (OLED).
  * Display sharpness is measured by **Resolution**, determined by total addressable **Pixels**.
* **Printers:**
  * **Impact Printers:** Characters produced by mechanical strike on ink ribbon against paper; noisy; examples: **Dot Matrix Printers (DMP)**, Daisy Wheel printers.
  * **Non-Impact Printers:** Quiet and high-speed; prints without physical mechanical striking.
    * *Inkjet Printer:* Sprays microscopic liquid droplets from fine nozzles.
    * *Laser Printer:* **Fastest and highest quality office printer**; utilizes a focused laser beam, electrostatic drum, and powdered dry pigment called **Toner**.
  * Printing throughput is rated in **PPM (Pages Per Minute)**; output resolution is rated in **DPI (Dots Per Inch)**.
* **Plotter:** High-precision vector hard-copy printing device designed for rendering architectural blueprints, engineering CAD schematics, and large flex banners.
* **Speakers, Headphones, and Digital Multimedia Projectors.**

*(Note: Touchscreens, Modems, and Fax machines function simultaneously as both Input and Output devices).*

### Part 5: Exam Revision Points

> [!TIP]
> 1. **Core Technologies by Generation:** 1st = Vacuum Tubes, 2nd = Transistors, 3rd = Integrated Circuits, 4th = Microprocessors (VLSI), 5th = Artificial Intelligence / ULSI.
> 2. **Brain of the Computer:** CPU (Comprising ALU, Control Unit, and Internal Registers).
> 3. **RAM vs ROM:** RAM is volatile (temporary read/write memory); ROM is non-volatile (permanent firmware housing BIOS).
> 4. **Speed Hierarchy:** Registers > L1/L2 Cache > Main RAM > Secondary SSD/HDD.
> 5. **Data Storage Conversions:** 1 Nibble = 4 bits; 1 Byte = 8 bits; 1 KB = 1024 Bytes.
> 6. **Banking Cheque Clearance:** MICR (Magnetic Ink Character Recognition - 9-digit magnetic code).
> 7. **CAD Blueprints:** Printed with precision using vector Plotters.
