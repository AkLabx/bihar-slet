## 1. Concept and History of Library Automation

> **Definition:** Library Automation refers to the application of computers, networking technologies, relational database systems, and associated information technologies to carry out traditional library housekeeping operations—such as acquisition, cataloguing, circulation, serials control, and reference service—with minimal human intervention and maximum operational efficiency.

### Etymology of Automation:
- The term **"Automation"** was coined in **1936** by **D. S. Harder**, Vice President of Manufacturing at **General Motors**, to describe the automatic handling and processing of components in automobile production lines.
- In library and information science, automation implies delegating repetitive, time-consuming, and clerical tasks to computerized systems, allowing professional library staff to focus on customized user assistance, information literacy, and knowledge curation.

### Chronological Milestones:
1. **The Punched-Card Era (1930s–1940s):**
   - In 1936, the **University of Texas** became a pioneer by utilizing Herman Hollerith's punched-card mechanical tabulating equipment to manage its circulation records.
2. **First Generation — Early Computerization (1960s):**
   - In 1965–1966, the **Library of Congress (LC)**, USA, initiated project **MARC (Machine-Readable Cataloging)** under the leadership of Henriette Avram. MARC-I (1966) and MARC-II (1968) laid the global foundation for standardized machine-readable cataloguing records.
3. **The Integrated Era (1970s–1980s):**
   - Modular, standalone computer programs were replaced by **Integrated Library Management Systems (ILMS)**. A single shared relational database allowed real-time synchronization between acquisition, cataloguing, circulation, and patron databases.
4. **The Internet, Web-OPAC, and Open-Source Era (1990s–Present):**
   - Shift from terminal-based systems to graphical web browsers, leading to Web-accessible Online Public Access Catalogues (Web-OPACs), open-source ILS platforms (Koha), and modern multi-tenant Software-as-a-Service (SaaS) cloud architectures.

## 2. Integrated Library Management Systems (ILMS)

A modern Integrated Library Management System (ILMS) relies on a centralized Relational Database Management System (RDBMS) where all functional modules share the same bibliographic and patron data:

```
                            [ Central Database / RDBMS ]
                                         |
     +---------------+---------------+---+-----------+---------------+
     |               |               |               |               |
[Acquisition]  [Cataloguing]   [Circulation]   [Serials Control] [Web-OPAC]
(Procurement)  (MARC-21/RDA)   (Issue/Return)  (Kardex/Issues)   (User Search)
     |
[Administration & Reporting Module]
```

### Core Modules of an ILMS:
1. **Acquisition Module:**
   - Automates title selection, duplicate checking, approval routing, generation of Purchase Orders (POs) to book vendors, budget allotment and tracking, invoice processing, currency conversion, and automated accession numbering.
2. **Cataloguing Module:**
   - Supports creating, editing, and indexing bibliographic and authority records conforming to **MARC-21**, **UNIMARC**, and **RDA** standards.
   - Provides **Copy Cataloguing** using the **Z39.50** and **SRU/SRW** client protocols to download verified catalog records directly from the Library of Congress, OCLC, or national libraries.
   - Generates barcodes and spine labels for physical processing.
3. **Circulation Module:**
   - Handles patron check-out (issue), check-in (return), renewals, holds/reservations, calculation and collection of overdue fines, patron account expiration, and patron category management.
4. **Serials Control Module:**
   - Manages annual journal subscriptions, renewal notifications, invoice processing, issue-by-issue check-in using digital predictive Kardex systems, claiming missing or delayed issues, and tracking binding schedules for completed volumes.
5. **Online Public Access Catalogue (OPAC / Web-OPAC):**
   - The user-facing search gateway enabling patrons to search the library holdings by title, author, subject, call number, publisher, or keywords with faceted filtering, reservation requests, and loan status checking.
6. **Administration & Reporting Module:**
   - System parameter configurations, circulation rule policies (loan periods, fine rates per patron type), user permission roles, automated system backups, and statistical reporting for annual library audits.

## 3. Koha — The World's First Open Source ILS

Koha is widely recognized as the world's first complete, enterprise-grade, open-source integrated library system.

### History and Development of Koha:
- **Meaning:** "Koha" is a word from the indigenous **Māori language** of New Zealand, meaning a **"Gift"**, **"Present"**, or **"Contribution"**.
- **Developer:** Commissioned by the **Horowhenua Library Trust (HLT)** in New Zealand and developed by **Katipo Communications Ltd.**
- **Initial Release:** Made fully operational and released on **January 1, 2000**.
- **Licensing:** Distributed under the **GNU General Public License (GPL)** version 2 or later, guaranteeing free access to source code, unrestricted redistribution, and community-driven modifications.

### Technical Specifications of Koha:
- **LAMP Architecture Stack:**
  - **L**inux (Operating System — predominantly Debian or Ubuntu LTS)
  - **A**pache (Web Server)
  - **M**ySQL / MariaDB (Relational Database Management System)
  - **P**erl (Primary Backend Programming Language)
- **International Standards Compliance:**
  - Full adherence to **MARC-21** and **UNIMARC** bibliographic and authority formats.
  - Built-in **Z39.50** client/server and **SRU/SRW** support for federated searching and copy cataloguing.
  - **SIP2 (Standard Interchange Protocol version 2):** Seamless integration with RFID self-service kiosks, book drops, and security gates.
  - **OAI-PMH:** Interoperability for institutional metadata harvesting.
- **Dual Web Interface:**
  - **Staff Client:** A comprehensive browser-based interface for library personnel requiring no local client installation.
  - **Web-OPAC:** A mobile-friendly, responsive portal for library patrons featuring user ratings, reviews, tag clouds, and digital reading history.

## 4. SOUL (Software for University Libraries)

SOUL is India's leading indigenous library automation software package, developed specifically to cater to university, college, and academic research libraries across India.

### History and Versions of SOUL:
- **Developer:** **INFLIBNET Centre (Information and Library Network Centre)**, an autonomous Inter-University Centre of the University Grants Commission (UGC), located in **Gandhinagar, Gujarat**.
- **Version Timeline:**
  - **SOUL 1.0:** Formally launched in **February 2000** at the CALIBER-2000 conference in Chennai. Designed on a Microsoft Access and FoxPro database architecture for Windows environments.
  - **SOUL 2.0:** Released in **January 2009**. Overhauled to support Microsoft SQL Server and MySQL, incorporating UNICODE compliance, multi-lingual support, and MARC-21 bibliographic standards.
  - **SOUL 3.0 (Latest):** Formally released in **February 2021**.

### Features and Modules of SOUL 3.0:
- **Web-Enabled Client-Server Architecture:** Modern web service interfaces, scalable for large university campus networks.
- **UNICODE and Multi-script Support:** Full data entry, indexing, and retrieval across all 22 official Indian languages recognized by the Eighth Schedule of the Indian Constitution.
- **Global Standards Integration:** Comprehensive compliance with MARC-21, MARCXML, Z39.50, and SIP2 (for RFID hardware integration).
- **Six Integrated Modules:**
  1. Acquisition
  2. Cataloguing
  3. Circulation
  4. Serials Control
  5. OPAC (Web-OPAC)
  6. Administration
- **Institutional Affordability:** Provided to Indian academic institutions at a nominal institutional fee with concessional upgrades for legacy users.

## 5. e-Granthalaya (National Informatics Centre)

e-Granthalaya is a flagship digital initiative spearheaded by the Government of India under the Digital India mission to computerize, network, and provide cloud services to public, school, and government department libraries across India.

### Development by NIC:
- **Nodal Agency:** Developed by the **National Informatics Centre (NIC)**, under the Ministry of Electronics and Information Technology (**MeitY**), Government of India.
- **Inception:** First launched in **2003** with desktop-centric standalone releases (Versions 1.0, 2.0, 3.0) implemented on local LAN platforms.
- **e-Granthalaya Version 4.0 (Cloud SaaS Model):**
  - **Software-as-a-Service (SaaS):** Individual school or college libraries do not need on-premises servers or dedicated database administrators. The application is hosted centrally on the **National Cloud of NIC (MeghRaj)**.
  - **Centralized Database:** Connects thousands of school libraries—including Kendriya Vidyalayas (KVS), Jawahar Navodaya Vidyalayas (NVS), state government schools, and public district libraries—into a single national repository.
  - **Key Features:** Zero local server maintenance cost, automated off-site data backups, mobile-responsive OPAC, automated SMS and email notifications to students, and compliance with UNICODE and MARC-21 standards.

## 6. Other Prominent Library Software

### (A) NewGenLib:
- **Developer:** Collaborative creation by **Verus Solutions Pvt. Ltd.** and the Keshav Memorial Technical Trust, Hyderabad, India.
- **Evolution:** Launched commercially in **2005**; released as a completely free **Open Source (GNU GPL)** software package in **March 2008**.
- **Technology Base:** Built using Java, Apache Tomcat web application server, and **PostgreSQL** relational database. Complies with MARC-21, Z39.50, and OAI-PMH.

### (B) CDS/ISIS and WINISIS (UNESCO):
- **CDS/ISIS (Computerized Documentation System / Integrated Set of Information Systems):**
  - **Developer:** Created in **1985** by **UNESCO** (Paris) under the leadership of Giampaolo Del Bigio.
  - **Nature:** Non-relational, variable-length textual database management system designed specifically for structured bibliographic records and information retrieval in developing countries. Written in Pascal.
- **WINISIS:**
  - The Microsoft Windows graphical user interface version of CDS/ISIS, released by UNESCO between **1995 and 1996**.

### (C) Commercial Proprietary Systems:
- **LibSys:** Developed by **LibSys Ltd.**, Gurgaon (Gurugram), India. First launched in **1984**. Dominates the Indian proprietary market across premier institutes such as IITs, IIMs, and major central universities (Versions: LibSys 4, LibSys 7, LibSys 10).
- **SLIM21 (System for Library Information Management):** Developed by Algorithms Consultants Pvt. Ltd., Pune, India.
