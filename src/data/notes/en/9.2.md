### Part 1: Operating Systems: Core Functions & Classification

* **Definition:** An Operating System (OS) is essential system software that serves as an **interface / mediator** between the computer hardware and human users or application software.
* **Core Operating System Functions:**
  1. *Processor Management (CPU Scheduling)* — Implements multiprogramming, multitasking, and time-slicing.
  2. *Memory Management (RAM Allocation)* — Dynamically allocates primary memory blocks and manages virtual memory swap space.
  3. *File System Management* — Organizes directories and files on storage drives (e.g., NTFS, FAT32, ext4).
  4. *Device & I/O Management* — Controls peripheral hardware through dedicated device drivers.
* **Booting Sequence:**
  * **Cold Booting (Hard Boot):** Powering up the computer system from a complete shutdown state.
  * **Warm Booting (Soft Boot):** Restarting an already running computer system without disconnecting main power (e.g., executing $Ctrl+Alt+Delete$).
  * **POST (Power-On Self-Test):** Initial diagnostic routine executed automatically by the BIOS upon power-on to verify operational integrity of memory, keyboard, and storage controllers.

| Operating System Architecture | Common Examples | Architectural Characteristics & Licensing |
|---|---|---|
| **Command Line Interface (CLI / CUI)** | MS-DOS, UNIX Bourne Shell | Relies strictly on typed textual command syntax. |
| **Graphical User Interface (GUI)** | Windows (10/11), macOS | Visual interaction using windows, icons, menus, and pointer clicks (WIMP paradigm). |
| **Open Source Operating Systems** | **Linux** (Ubuntu, RedHat, Debian, Fedora), Android | Source code is freely accessible, editable, and distributable without licensing fees. Linux kernel was originally created by **Linus Torvalds** in 1991. |
| **Proprietary / Closed Source OS** | Microsoft Windows, macOS, iOS | Commercial closed-source software with proprietary source code guarded by vendor copyrights. |
| **Mobile Operating Systems** | Android (Google - Linux based), iOS (Apple) | Touch-optimized embedded operating systems for portable mobile hardware. |

### Part 2: Microsoft Office Productivity Suite: Word, Excel & PowerPoint

#### A. Microsoft Word (Word Processing Software)
* **Default Document Extension:** `.docx` (Office 2007 to present) and legacy `.doc`.
* **High-Yield Keyboard Shortcuts:**
  * $Ctrl + A$: Select All text and graphical elements in document.
  * $Ctrl + C$ / $Ctrl + X$ / $Ctrl + V$: Copy / Cut / Paste.
  * $Ctrl + Z$ / $Ctrl + Y$: Undo / Redo action.
  * $Ctrl + F$ / $Ctrl + H$: Find / Replace dialog.
  * $Ctrl + K$: **Insert Hyperlink**.
  * $Ctrl + B$ / $Ctrl + I$ / $Ctrl + U$: Bold / Italic / Underline formatting.
  * **Text Alignment:** $Ctrl + L$ (Left), $Ctrl + E$ (Center), $Ctrl + R$ (Right), $Ctrl + J$ (Justify).
  * $F7$: **Spelling and Grammar Check**.
  * $Shift + F7$: **Thesaurus Lookup** (Find synonyms and antonyms).

#### B. Microsoft Excel (Spreadsheet & Data Analysis)
* **Default Workbook Extension:** `.xlsx` (Legacy: `.xls`).
* **Basic Structural Grid:** A Workbook contains individual Worksheets. A Worksheet consists of horizontal Rows (numbered 1, 2, 3...) and vertical Columns (alphabetized A, B, C...).
* **Cell & Name Box:** The intersection of a row and a column forms a Cell. The address of the currently active cell is displayed in the **Name Box** (e.g., `B5`).
* **Formula Syntax Rule:** In Excel, every formula or computational function MUST begin with the **'=' (equals sign)** (e.g., `=SUM(A1:A10)` or `=AVERAGE(B1:B5)`).
* **High-Yield Excel Shortcuts:**
  * $F2$: **Edit** active cell contents.
  * $Alt + =$: Instantly insert **AutoSum** formula.
  * $F4$: Toggle absolute/relative cell references (locks coordinates with \$ symbol).
  * $Ctrl + ;$: Insert current system date.

#### C. Microsoft PowerPoint (Presentation Graphics)
* **Default Presentation Extension:** `.pptx`.
* **Slide Show Controls & Shortcuts:**
  * $F5$: Start Slide Show from the **First Slide**.
  * $Shift + F5$: Start Slide Show from the **Current Active Slide**.
  * $Esc$: Terminate Slide Show presentation immediately.
  * $Ctrl + M$: **Insert New Slide** into active presentation *(Caution: $Ctrl+N$ creates an entirely new presentation file)*.

### Part 3: Networking Topologies, Internet & Communication Protocols

```
         ┌─── 1. LAN (Local Area Network) ─── Confined to a single room, building, or school campus (< 1 km)
Network ─┼─── 2. MAN (Metropolitan Area Network) ─── Spans an entire city or municipal zone (e.g., Cable TV network)
Types    └─── 3. WAN (Wide Area Network) ─── Spans states, countries, or globe (The Internet is the largest WAN)
```

#### A. Internet Architecture & Foundational Protocols
* **Fathers of the Internet:** **Vinton Cerf** and Bob Kahn (Co-designers of the TCP/IP protocol suite).
* **World Wide Web (WWW):** Invented in 1989 by British scientist **Sir Tim Berners-Lee** at CERN, Switzerland.
* **Network Protocol Chart:**

| Protocol | Full Name | Operational Role & Port Number |
|---|---|---|
| **TCP/IP** | Transmission Control Protocol / Internet Protocol | Core communications suite of the Internet; divides data streams into packets, tracks routing, and ensures end-to-end delivery. |
| **HTTP / HTTPS** | Hypertext Transfer Protocol (Secure) | Web page transmission; HTTPS encrypts communications using **SSL/TLS certificates** (Standard Port: 443). |
| **FTP** | File Transfer Protocol | Uploading and downloading files across client-server network architecture (Ports 20/21). |
| **DNS** | Domain Name System | Translates human-readable domain names (e.g., `bihar.gov.in`) into numeric machine IP addresses (e.g., `164.100.150.10`). Termed the 'Phonebook of the Internet'. |
| **DHCP** | Dynamic Host Configuration Protocol | Automatically assigns dynamic IP addresses and network parameters to devices connected to a subnet. |

#### B. Electronic Mail (Email) Protocols
* **SMTP (Simple Mail Transfer Protocol):** Governs **Outgoing email transmission** from client to mail servers or between mail servers (Standard Port: 25).
* **POP3 (Post Office Protocol version 3):** Retrieves and downloads **Incoming email** from a remote mail server directly to the local client machine, typically deleting it from the server.
* **IMAP (Internet Message Access Protocol):** Reads emails directly on the remote cloud server, maintaining continuous synchronization across multiple client devices (phones, laptops).
* **Email Addressing:** `username@domain.com` | **CC (Carbon Copy):** Secondary recipients visible to all parties. **BCC (Blind Carbon Copy):** Hidden recipient addresses concealed from all other recipients for privacy.

### Part 4: Cyber Security, Malware & Defensive Mechanisms

#### A. Major Categories of Malware (Malicious Software)

| Malware Classification | Operating Mechanism & Detrimental Impact |
|---|---|
| **Computer Virus** | • Vital Information Resources Under Siege.<br>• Attaches malicious code to legitimate host executable files (.exe) and propagates upon execution, corrupting files and system data.<br>• First commercial PC virus: **'Brain' (1986)**. |
| **Computer Worm** | • Self-replicating standalone malicious program that operates without attaching to host files.<br>• Exploits network vulnerabilities to replicate across nodes, saturating system memory and network bandwidth. |
| **Trojan Horse** | • Disguises itself as legitimate, harmless, or useful utility software, but creates a hidden backdoor allowing unauthorized remote attackers to control the compromised machine. |
| **Ransomware** | • Employs military-grade cryptographic encryption to lock user data files, demanding extortionate financial ransom (often in cryptocurrency like Bitcoin) for decryption keys (e.g., WannaCry, Petya). |
| **Spyware & Keyloggers** | • Operates covertly in the background without user consent, monitoring browsing activity and logging keyboard keystrokes to steal bank credentials and personal passwords. |

#### B. Major Cyber Attacks & Defensive Safeguards
* **Phishing:** Social engineering attack where fraudulent emails or spoofed websites resembling trusted institutions (banks, income tax agencies) deceive users into divulging confidential login credentials, OTPs, or credit card numbers.
* **Spoofing:** Falsifying network identity or IP/email headers to masquerade as a legitimate trusted source.
* **DoS / DDoS (Denial of Service):** Overwhelming a targeted web server with an artificial flood of millions of bogus network requests, crashing the server and rendering services unavailable to legitimate users.
* **Firewall:** A dedicated security gateway (implemented in software or specialized hardware) that monitors and filters incoming and outgoing network traffic based on predetermined access control rules.
* **Indian Information Technology Act, 2000 (IT Act 2000):**
  * Effective Date: October 17, 2000.
  * Sections 43 & 66: Penalties for unauthorized hacking, tampering with computer source code, and digital damage.
  * Section 66E: Punishment for violation of digital bodily privacy.
