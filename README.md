## 📖 परियोजना परिचय (Project Overview)

यह ओपन-सोर्स वेब पोर्टल **बिहार विद्यालय पुस्तकालयाध्यक्ष पात्रता परीक्षा 2026 (Bihar State Librarian Eligibility Test - SLET / LET)** के संपूर्ण **150 अंक** पाठ्यक्रम की तैयारी हेतु तैयार किया गया है। 

परीक्षा बिहार विद्यालय परीक्षा समिति (BSEB) एवं शिक्षा विभाग द्वारा आयोजित की जाएगी। इसमें पुस्तकालय एवं सूचना विज्ञान (स्नातक/BLIS स्तर) से **100 प्रश्न** और सामान्य ज्ञान व तार्किक क्षमता से **50 प्रश्न** पूछे जाएंगे।

🔗 **लाइव वेब पोर्टल:** [https://aklabx.github.io/bihar-slet/](https://aklabx.github.io/bihar-slet/)

## 📚 पाठ्यक्रम कवरेज (100% Complete Syllabus Breakdown)

### भाग-1: पुस्तकालय एवं सूचना विज्ञान (LIS — 100 अंक • 295 MCQs)
1. **इकाई 1: पुस्तकालय की नींव एवं समाज (55 MCQs)** — पुस्तकालय के प्रकार, डॉ. एस.आर. रंगनाथन एवं पाँच सूत्र, पुस्तकालय आंदोलन व अधिनियम, संघ (ILA, IASLIC, IFLA, ALA, UNESCO)।
2. **इकाई 2: पुस्तकालय प्रबंधन एवं संगठन (60 MCQs)** — संग्रह विकास, परिसंचरण तंत्र (Browne, Newark), बजट, भंडार सत्यापन, पुस्तक निष्कासन, HRM एवं TQM।
3. **इकाई 3: ज्ञान संगठन: वर्गीकरण एवं सूचीकरण (30 MCQs)** — DDC, UDC, CC, AACR-2, RDA, MARC-21, ISBD, OPAC व अनुक्रमणीकरण।
4. **इकाई 4: संदर्भ एवं सूचना सेवाएं (60 MCQs)** — प्राथमिक/द्वितीयक/तृतीयक स्रोत, संदर्भ ग्रंथ, CAS, SDI, DDS, अंतर-पुस्तकालय ऋण, उपयोगकर्ता शिक्षा।
5. **इकाई 5: सूचना प्रौद्योगिकी, ऑटोमेशन एवं नेटवर्किंग (60 MCQs)** — KOHA, SOUL, ई-ग्रंथालय, बारकोड, RFID, DSpace, शोधगंगा, NDL, INFLIBNET, DELNET।
6. **इकाई 6: सूचना विज्ञान, शोध एवं मानक (30 MCQs)** — ग्रंथमिति (Bradford, Lotka, Zipf के नियम), ISBN, ISSN, कॉपीराइट एवं बौद्धिक संपदा अधिकार (IPR)।

### भाग-2: सामान्य ज्ञान एवं मानसिक योग्यता (50 अंक • 150 MCQs)
7. **इकाई 7: बिहार विशेष: इतिहास, भूगोल, कला व आंदोलन (45 MCQs)** — 1857 की क्रांति (वीर कुंवर सिंह), चंपारण सत्याग्रह, 1942 आंदोलन, बिहार भूगोल, नदियां, खनिज, जनगणना 2011, मधुबनी चित्रकला, छठ पर्व, प्रमुख विभूतियां।
8. **इकाई 8: भारतीय राजव्यवस्था, विज्ञान एवं समसामयिकी (45 MCQs)** — संविधान, मौलिक अधिकार, पंचायती राज (बिहार 50% महिला आरक्षण), सामान्य विज्ञान, पर्यावरण, सात निश्चय-2, चंद्रयान-3।
9. **इकाई 9: बुनियादी कंप्यूटर ज्ञान एवं सूचना प्रौद्योगिकी (30 MCQs)** — कंप्यूटर पीढ़ियां, मेमोरी (RAM/ROM), ऑपरेटिंग सिस्टम, MS Office शॉर्टकट, इंटरनेट, साइबर सुरक्षा।
10. **इकाई 10: तार्किक क्षमता एवं मानसिक योग्यता (30 MCQs)** — कोडिंग-डिकोडिंग, शृंखला, दिशा परीक्षण, रक्त संबंध, न्याय निगमन (Syllogism), वेन आरेख।

## ⚡ प्रमुख विशेषताएं (Key Features)

- **100% द्विभाषी (Bilingual Parity):** प्रत्येक अध्ययन नोट और प्रश्न हिंदी एवं अंग्रेजी दोनों में उपलब्ध है। 3-वे टॉगल (`द्विभाषी`, `हिंदी`, `English`) के जरिए भाषा बदल सकते हैं।
- **दोहरी परीक्षण प्रणाली (Dual Test Modes):**
  - **अभ्यास मोड (Practice Mode):** विकल्प चुनते ही तत्काल सही/गलत का रंग-संकेत एवं विस्तृत विश्लेषणात्मक व्याख्या।
  - **परीक्षा मोड (Exam Mode):** 20 मिनट का टाइमर, प्रश्न पैलेट, समीक्षा हेतु चिह्नित करने की सुविधा, और अंत में प्रामाणिक कटऑफ स्कोरकार्ड।
- **150 प्रश्नों का सम्पूर्ण ग्रैंड मॉक टेस्ट (Grand Mock Test):** 100 LIS प्रश्न + 50 GK प्रश्न, 150 मिनट का वास्तविक परीक्षा टाइमर और श्रेणीवार उत्तीर्णता परिणाम।
- **Zustand स्टेट मैनेजमेंट:** कुल हल किए गए प्रश्नों की प्रगति, सटीकता %, गलत प्रश्नों का स्वतः विश्लेषण, और कठिन प्रश्नों को बुकमार्क करने की सुविधा।
- **GitHub Pages कम्पैटिबल:** `HashRouter` (`/#/study/1.1`) के कारण GitHub Pages पर 404 त्रुटि की कोई संभावना नहीं।

## 🛠️ तकनीकी संरचना (Tech Stack)

- **कोर फ्रेमवर्क:** React 18 / 19 + TypeScript
- **बिल्ड टूल:** Vite 6
- **रूटिंग:** React Router (HashRouter)
- **स्टेट मैनेजमेंट:** Zustand (LocalStorage Persistence)
- **स्टाइलिंग:** Tailwind CSS (डार्क/लाइट मोड सपोर्ट)
- **आइकन्स:** Lucide React
- **टेस्टिंग:** Vitest (445 प्रश्नों की स्वचालित स्कीमा जांच)
- **CI/CD:** GitHub Actions (Pre-Merge CI + GitHub Pages Deploy)

## 💻 स्थानीय विकास सेटअप (Local Development)

```bash
# 1. रिपॉजिटरी क्लोन करें
git clone https://github.com/AkLabx/bihar-slet.git
cd bihar-slet

# 2. डिपेंडेंसी इंस्टॉल करें
npm install

# 3. 445 प्रश्नों के स्कीमा व डेटा टेस्ट रन करें
npm test

# 4. लोकल डेवलपमेंट सर्वर शुरू करें
npm run dev

# 5. प्रोडक्शन बिल्ड तैयार करें
npm run build
```

## 🚀 GitHub Actions CI/CD पाइपलाइन

- **`ci.yml` (Pre-Merge Validation):** किसी भी Pull Request पर स्वचालित रूप से Vitest के 5 व्यापक टेस्ट चलाता है, TypeScript प्रकारों की पुष्टि करता है, और प्रोडक्शन बिल्ड का परीक्षण करता है। CI टेस्ट पास होने के बाद ही कोड `main` में मर्ज हो सकता है।
- **`deploy.yml` (Auto Deploy):** `main` ब्रांच में कोड आते ही Vite प्रोजेक्ट को कंपाइल करता है और `dist/` डायरेक्टरी को सीधे GitHub Pages पर लाइव कर देता है।
