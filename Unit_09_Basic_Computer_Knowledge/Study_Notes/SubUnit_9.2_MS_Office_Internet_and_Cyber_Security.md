## 1. ऑपरेटिंग सिस्टम: कार्य एवं प्रकार (Operating Systems - OS)

* **परिभाषा:** ऑपरेटिंग सिस्टम सिस्टम सॉफ्टवेयर है जो यूजर और कंप्यूटर हार्डवेयर के बीच एक **इंटरफेस (Interface / मध्यस्थ)** का कार्य करता है।
* **प्रमुख कार्य:**
  1. *प्रोसेसर प्रबंधन (CPU Scheduling)* — मल्टीप्रोग्रामिंग व टाइम शेयरिंग।
  2. *मेमोरी प्रबंधन (Memory Allocation)* — RAM व वर्चुअल मेमोरी का आवंटन।
  3. *फाइल प्रबंधन (File System)* — फाइलों को डायरेक्टरी/फोल्डर में सुरक्षित रखना (NTFS, FAT32)।
  4. *डिवाइस प्रबंधन* — डिवाइस ड्राइवर्स द्वारा इनपुट/आउटपुट उपकरणों का नियंत्रण।
* **बूटिंग प्रक्रिया (Booting Process):**
  * **कोल्ड बूटिंग (Cold Booting):** कंप्यूटर के पूर्णतः बंद (Power Off) अवस्था से ऑन करने की प्रक्रिया।
  * **वार्म बूटिंग (Warm Booting):** पहले से चालू कंप्यूटर को रीस्टार्ट (Restart / $Ctrl+Alt+Delete$) करना।
  * **POST (Power-On Self-Test):** कंप्यूटर चालू होते ही BIOS द्वारा सभी हार्डवेयर घटकों की कार्यक्षमता की स्व-जांच।

| ऑपरेटिंग सिस्टम (OS Type) | उदाहरण (Examples) | विशेषताएं एवं लाइसेंस (Key Features & License) |
|---|---|---|
| **कमांड लाइन (CUI / CLI)** | MS-DOS, UNIX Shell | केवल टेक्स्ट कमांड टाइप करके संचालन। |
| **ग्राफिकल यूजर इंटरफेस (GUI)** | Windows (10/11), macOS | आइकॉन्स, मेन्यू, माउस क्लिक द्वारा सरल संचालन। |
| **ओपन सोर्स (Open Source OS)** | **Linux** (Ubuntu, RedHat, Debian), Android | स्रोत कोड (Source Code) सार्वजनिक रूप से निशुल्क उपलब्ध एवं संपादन योग्य। लिनक्स कर्नल के निर्माता: **लिनुस टॉर्वाल्ड्स (1991)**। |
| **क्लोज्ड / प्रोप्राइटरी (Proprietary)** | Microsoft Windows, macOS, iOS | वाणिज्यिक लाइसेंस प्राप्त; कोड गुप्त रहता है। |
| **मोबाइल ऑपरेटिंग सिस्टम** | Android (Google - Linux आधारित), iOS (Apple) | टच-आधारित पोर्टेबल डिवाइस OS। |

## 2. माइक्रोसॉफ्ट ऑफिस सूट: वर्ड, एक्सेल एवं पावरपॉइंट (MS Office Essentials)

### क. एमएस वर्ड (MS Word — वर्ड प्रोसेसर)
* **डिफॉल्ट फाइल एक्सटेंशन:** `.docx` (Office 2007 से वर्तमान) एवं `.doc` (पुराने संस्करण)।
* **महत्वपूर्ण शॉर्टकट कुंजियां (High-Yield Shortcuts):**
  * $Ctrl + A$: संपूर्ण दस्तावेज का चयन (Select All)
  * $Ctrl + C$ / $Ctrl + X$ / $Ctrl + V$: कॉपी / कट / पेस्ट
  * $Ctrl + Z$ / $Ctrl + Y$: अंडू (Undo) / रीडू (Redo)
  * $Ctrl + F$ / $Ctrl + H$: फाइंड (Find) / रिप्लेस (Replace)
  * $Ctrl + K$: **हाइपरलिंक प्रविष्ट करना (Insert Hyperlink)**
  * $Ctrl + B$ / $Ctrl + I$ / $Ctrl + U$: बोल्ड / इटैलिक / रेखांकित (Underline)
  * **संरेखण (Alignment):** $Ctrl + L$ (Left), $Ctrl + E$ (Center), $Ctrl + R$ (Right), $Ctrl + J$ (Justify)
  * $F7$: **वर्तनी एवं व्याकरण जांच (Spelling & Grammar Check)**
  * $Shift + F7$: **थिसॉरस (Thesaurus — समानार्थी शब्दकोश खोजना)**

### ख. एमएस एक्सेल (MS Excel — स्प्रेडशीट सॉफ्टवेयर)
* **डिफॉल्ट फाइल एक्सटेंशन:** `.xlsx` (पुराना: `.xls`)।
* **मूलभूत संरचना:** वर्कबुक (फाइल) में अनेक वर्कशीट्स होती हैं। वर्कशीट में पंक्तियां (Rows - संख्या 1, 2, 3...) तथा स्तंभ (Columns - अक्षर A, B, C...) होते हैं।
* **सेल (Cell):** पंक्ति और स्तंभ का कटान बिंदु। सक्रिय सेल का पता (Address) **'नेम बॉक्स' (Name Box)** में प्रदर्शित होता है (जैसे `B5`)।
* **फॉर्मूला नियम:** एक्सेल में कोई भी फॉर्मूला हमेशा **'=' (बराबर के चिह्न)** से शुरू होता है (जैसे `=SUM(A1:A10)` या `=AVERAGE(B1:B5)`).
* **प्रमुख शॉर्टकट कुंजियां:**
  * $F2$: सक्रिय सेल को **संपादित (Edit)** करना
  * $Alt + =$: **AutoSum (त्वरित योग)** फंक्शन जोड़ना
  * $F4$: सेल संदर्भ को एब्सोल्यूट/स्थिर (Lock with \$) करना
  * $Ctrl + ;$: आज की वर्तमान तारीख (Current Date) प्रविष्ट करना

### ग. एमएस पावरपॉइंट (MS PowerPoint — प्रेजेंटेशन सॉफ्टवेयर)
* **डिफॉल्ट फाइल एक्सटेंशन:** `.pptx`।
* **स्लाइड शो कुंजियां:**
  * $F5$: प्रेजेंटेशन को **प्रथम स्लाइड से** स्लाइड शो मोड में चलाना
  * $Shift + F5$: **वर्तमान (Current) सक्रिय स्लाइड से** स्लाइड शो शुरू करना
  * $Esc$: स्लाइड शो को तुरंत समाप्त करना
  * $Ctrl + M$: प्रेजेंटेशन में **नई स्लाइड (New Slide) जोड़ना** *(सावधानी: $Ctrl+N$ नई प्रेजेंटेशन फाइल खोलता है)*

## 3. नेटवर्किंग, इंटरनेट एवं ईमेल प्रोटोकॉल (Networking & Internet)

```
        ┌─── 1. LAN (Local Area Network) ─── एक कक्ष, भवन या परिसर (1 किमी तक)
नेटवर्क ────┼─── 2. MAN (Metropolitan Area Network) ─── एक संपूर्ण नगर/शहर (केबल टीवी नेटवर्क)
के प्रकार └─── 3. WAN (Wide Area Network) ─── राष्ट्रीय/अंतरराष्ट्रीय स्तर (इंटरनेट सबसे बड़ा WAN है)
```

### क. इंटरनेट एवं प्रमुख प्रोटोकॉल (Internet Protocols)
* **इंटरनेट के जनक:** **विंटन सेर्फ़ (Vinton Cerf)** एवं बॉब काह्न (TCP/IP के सह-निर्माता)।
* **WWW (World Wide Web):** 1989 में स्विट्जरलैंड की CERN प्रयोगशाला में **टिम बर्नर्स ली (Tim Berners-Lee)** द्वारा आविष्कृत।
* **प्रोटोकॉल चार्ट:**

| प्रोटोकॉल (Protocol) | पूर्ण रूप (Full Form) | कार्य एवं उपयोग (Function & Standard Port) |
|---|---|---|
| **TCP/IP** | Transmission Control Protocol / Internet Protocol | इंटरनेट का मूल नियम समूह; डेटा को पैकेटों में तोड़ना व गंतव्य पते पर पहुंचाना। |
| **HTTP / HTTPS** | Hypertext Transfer Protocol (Secure) | वेब पेजों का अंतरण; HTTPS में डेटा **SSL/TLS एन्क्रिप्शन** द्वारा सुरक्षित होता है (Port 443)। |
| **FTP** | File Transfer Protocol | नेटवर्क पर फाइलों को अपलोड व डाउनलोड करने हेतु (Port 20/21)। |
| **DNS** | Domain Name System | मानव-पठनीय डोमेन नाम (जैसे `bihar.gov.in`) को संख्यात्मक IP पते (जैसे `164.100.150.10`) में बदलना। इसे 'इंटरनेट की फोनबुक' कहते हैं। |
| **DHCP** | Dynamic Host Configuration Protocol | नेटवर्क में जुड़े कंप्यूटरों को स्वचालित रूप से IP एड्रेस आवंटित करना। |

### ख. ईमेल संचार प्रोटोकॉल (Email Communication Protocols)
* **SMTP (Simple Mail Transfer Protocol):** क्लाइंट से सर्वर तक ईमेल **भेजने (Outgoing / Sending Mail)** के लिए उत्तरदायी प्रोटोकॉल (मानक पोर्ट: 25)।
* **POP3 (Post Office Protocol v3):** मेल सर्वर से अपने कंप्यूटर पर ईमेल **प्राप्त करने / डाउनलोड करने (Incoming / Downloading Mail)** हेतु।
* **IMAP (Internet Message Access Protocol):** ईमेल को सीधे सर्वर पर रहकर पढ़ने और कई उपकरणों (मोबाइल, लैपटॉप) में सिंक रखने हेतु।
* **ईमेल संरचना:** `username@domain.com` | **CC (Carbon Copy):** सभी प्राप्तकर्ताओं को अन्य प्राप्तकर्ताओं के पते दिखते हैं। **BCC (Blind Carbon Copy):** इसमें दर्ज ईमेल पते किसी अन्य प्राप्तकर्ता को दिखाई नहीं देते (गोपनीयता)।

## 4. साइबर सुरक्षा एवं डिजिटल खतरे (Cyber Security & Threats)

### क. प्रमुख मैलवेयर (Malware - Malicious Software)

| मैलवेयर का प्रकार (Malware Type) | कार्यप्रणाली एवं प्रभाव (Mechanism & Harmful Impact) |
|---|---|
| **कंप्यूटर वायरस (Virus)** | • Vital Information Resources Under Siege.<br>• किसी निष्पादन योग्य फाइल (.exe आदि) से जुड़कर अपनी प्रतियां बनाता है और फाइलों को दूषित करता है।<br>• विश्व का प्रथम पीसी वायरस: **'ब्रेन' (Brain - 1986)**। |
| **वॉर्म (Computer Worm)** | • वायरस के विपरीत, इसे फैलने के लिए किसी होस्ट फाइल की जरूरत नहीं होती।<br>• यह नेटवर्क की सुरक्षा खामियों का लाभ उठाकर स्वयं की लाखों प्रतियां बनाकर मेमोरी व बैंडविड्थ जाम कर देता है। |
| **ट्रोजन हॉर्स (Trojan Horse)** | • एक **धोखेबाज प्रोग्राम** जो बाहर से उपयोगी या मनोरंजक सॉफ्टवेयर दिखता है, किंतु इंस्टॉल होने पर कंप्यूटर में हैकर्स के लिए 'बैकडोर' (चोर दरवाजा) खोल देता है। |
| **रैंसमवेयर (Ransomware)** | • उपयोगकर्ता के कंप्यूटर की सभी फाइलों को मजबूत क्रिप्टोग्राफी से **एन्क्रिप्ट (तालाबंद)** कर देता है तथा डिक्रिप्शन की (Key) के बदले फिरौती (Ransom / बिटकॉइन) की मांग करता है (जैसे WannaCry, Petya)। |
| **स्पाइवेयर एवं कीलॉगर (Spyware & Keylogger)**| • उपयोगकर्ता की अनुमति के बिना पृष्ठभूमि में रहकर इंटरनेट गतिविधियों, बैंक विवरण एवं कीबोर्ड पर दबाए गए बटनों (Keystrokes) को रिकॉर्ड कर हैकर को भेजना। |

### ख. प्रमुख साइबर हमले एवं सुरक्षा शब्दावली (Attacks & Defenses)
* **फ़िशिंग (Phishing):** वास्तविक बैंक, आयकर विभाग या सोशल मीडिया जैसी दिखने वाली फर्जी वेबसाइटें/ईमेल बनाकर उपयोगकर्ताओं को झांसा देकर उनके गोपनीय पासवर्ड, क्रेडिट कार्ड पिन या ओटीपी चुराना।
* **स्पूफिंग (Spoofing):** अपनी वास्तविक पहचान छिपाकर किसी प्रामाणिक स्रोत या IP पते का नकली मुखौटा धारण करना।
* **DoS / DDoS (Denial of Service):** किसी वेब सर्वर पर अचानक लाखों फर्जी अनुरोध (Requests) भेजकर सर्वर को क्रैश या अनुपलब्ध कर देना।
* **फ़ायरवॉल (Firewall):** किसी निजी नेटवर्क (LAN) और बाहरी असुरक्षित नेटवर्क (इंटरनेट) के बीच आने-जाने वाले डेटा पैकेट्स की जांच करने और अनधिकृत प्रवेश रोकने वाला **सुरक्षा फिल्टर (हार्डवेयर या सॉफ्टवेयर)**।
* **भारतीय सूचना प्रौद्योगिकी अधिनियम, 2000 (IT Act 2000):**
  * प्रभावी: 17 अक्टूबर 2000।
  * धारा 43 व 66: कंप्यूटर सिस्टम को नुकसान पहुंचाने व अनधिकृत हैकिंग हेतु दंड।
  * धारा 66E: निजता उल्लंघन हेतु दंड।

## 5. परीक्षा-उपयोगी स्मरणीय सूत्र (Quick Exam Memory Points)

> [!IMPORTANT]
> 1. **लिनक्स (Linux):** ओपन-सोर्स OS (लिनुस टॉर्वाल्ड्स 1991)।
> 2. **MS Word शॉर्टकट्स:** $Ctrl+K$ = हाइपरलिंक, $F7$ = स्पेलिंग चेक, $Shift+F7$ = थिसॉरस।
> 3. **MS Excel:** फॉर्मूला हमेशा '=' से शुरू होता है; सेल पता 'नेम बॉक्स' में दिखता है; $Alt+=$ = AutoSum।
> 4. **MS PowerPoint:** $F5$ = आरंभ से स्लाइड शो, $Shift+F5$ = वर्तमान स्लाइड से, $Ctrl+M$ = नई स्लाइड।
> 5. **ईमेल प्रोटोकॉल:** भेजने के लिए = SMTP (Port 25); प्राप्त करने के लिए = POP3 / IMAP।
> 6. **DNS:** डोमेन नेम को IP एड्रेस में अनुवाद करना।
> 7. **फ़िशिंग:** फर्जी ईमेल/वेबसाइट द्वारा वित्तीय पासवर्ड चुराना।
> 8. **फ़ायरवॉल:** अनधिकृत नेटवर्क ट्रैफिक को रोकने वाला सुरक्षा कवच।
